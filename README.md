**CkcK** (*Cik-Cak*) is an open-source, zero-bloat transit aggregator designed to replace the fragmented soup of Slovenian transport apps (Urbana, Arriva, Nomago).

Stop opening four different apps just to check if you can make a transfer. Just **CkcK** it.

---

##  Key Features

-  **Unified Schedules:** Real-time and scheduled arrivals across municipal (LPP/Urbana), intercity (Arriva, Nomago), and rail systems (SŽ).
-  **Multi-Hop Routing:** Algorithmically links buses, trains, and shared rides into a single coherent itinerary.
-  **Offline-First Data Caching:** Light payloads, instant startup times, zero battery bleed.
-  **Privacy-Preserving:** No registration wall, no location history farming, no third-party telemetry.
